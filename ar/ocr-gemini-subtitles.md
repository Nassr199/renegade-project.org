# مشروع OCR لاستخراج الترجمة العربية باستخدام Gemini

## الفكرة
هذه الصفحة مخصّصة لتوثيق مشروع OCR يقوم باستخراج نصوص الترجمة العربية من فيديوهات المسلسلات والأفلام (خصوصًا النص الموجود في الجزء السفلي من المشهد)، ثم معالجتها باستخدام نماذج **Gemini**.

## الهدف
- التقاط إطارات الفيديو بذكاء (حسب المشاهد أو الزمن).
- تحديد منطقة الترجمة العربية تلقائيًا (Subtitle Region Detection).
- تنفيذ OCR عربي بدقة عالية.
- تنظيف النصوص (إزالة الضجيج، تصحيح الاتجاه، توحيد الحروف).
- استخدام Gemini لتحسين الصياغة/التصحيح/الترجمة/التصنيف حسب الحاجة.
- تصدير النتائج بصيغ مثل `SRT` و`JSON`.

## مخطط عمل مبدئي
1. **Frame Sampling**: سحب لقطات كل X ملّي ثانية أو عند تغيّر المشهد.
2. **Subtitle Detection**: اكتشاف منطقة النص في أسفل الشاشة.
3. **Arabic OCR**: تحويل الصورة إلى نص عربي.
4. **Post-processing**: تنظيف وتصحيح النص.
5. **Gemini Stage**: تحسين الفقرات وربط السطور زمنيًا.
6. **Export**: إنشاء ملفات ترجمة نهائية.

## متطلبات أولية
- Python 3.11+
- OpenCV
- OCR engine يدعم العربية
- Google Gemini API Key
- أدوات معالجة فيديو (`ffmpeg`)
